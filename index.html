Quick user guide

এই Prompt Generator কীভাবে ব্যবহার করবেন?

এই অ্যাপটি আপনার দেওয়া তথ্যের ভিত্তিতে একটি সম্পূর্ণ image-generation prompt তৈরি করে। এটি নিজে ছবি তৈরি করে না এবং এখান থেকে নির্বাচিত ছবি ChatGPT-তে পাঠায় না।

  1. একটি Visual Mode বেছে নিনবাম দিকের তালিকা থেকে Product X-Ray, Lifestyle, Feature Breakdown ইত্যাদির মধ্যে প্রয়োজনীয় পদ্ধতিটি নির্বাচন করুন।
  2. পণ্যের তথ্য পূরণ করুনProduct Name, Description, Ideal Customer এবং নির্বাচিত Mode অনুযায়ী প্রয়োজনীয় তথ্য লিখুন। অজানা তথ্য বানিয়ে লিখবেন না।
  3. Prompt তৈরি করুনVisual Text Language, Image Ratio, Visual Direction ও Platform নির্বাচন করে Generate Prompt চাপুন।
  4. Prompt Copy করুনCopy Prompt বাটনে চাপুন। চাইলে Download .txt দিয়ে prompt-টি ফাইল হিসেবেও রাখতে পারবেন।
  5. ছবি সরাসরি ChatGPT-তে Upload করুনএই HTML পেজে ছবি আপলোড করার প্রয়োজন নেই। ChatGPT-তে নতুন বা বর্তমান চ্যাটে ছবিটি সরাসরি attach করুন, তারপর কপি করা prompt পাঠান।
কোন Mode-এ কোন ছবি দেবেন?
  • Product X-Ray, Lifestyle, Anatomy, Feature Breakdown, Usage Demonstration, Problem-Solution: আসল পণ্যের ছবি ChatGPT-তে attach করুন।
  • Before & After: আগে তৈরি করা finished Product X-Ray image attach করুন।
  • Product Comparison: দুটি পণ্যের আসল ছবিই attach করুন।
মনে রাখবেন

ছবি attach করা এবং prompt পাঠানো—দুটিই ChatGPT-তে আপনাকেই করতে হবে। এই পেজে আপনার লেখা তথ্য browser-এ prompt তৈরির জন্য ব্যবহার হয়; কোনও AI service-এ স্বয়ংক্রিয়ভাবে পাঠানো হয় না।
